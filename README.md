# My Portfolio – Ann Peter Wayua

A simple and beautiful portfolio I built during **eMobilis Web Development Bootcamp**.

---

## What It Does

- 4 pages: **Home**, **About**, **Projects**, **Contact**  
- Dark & Light mode (stays the same when you switch pages)  
- Cool background with moving particles  
- Works on phone, tablet, and computer  
- "Show More" button to see extra projects  
- Contact form with glowing effects  

---

## How I Built It

- **HTML** → Page structure  
- **CSS** → Colors, animations, responsive design  
- **JavaScript** → Theme switch, Show More, form  

---

## How to Open

1. Download this folder  
2. Open `index.html` in your browser  
3. That's it!
